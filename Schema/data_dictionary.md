# Data Dictionary

| Field | Meaning |
|---|---|
| source_id | Unique identifier for the source record |
| source_url | Official URL used for retrieval |
| collection_date | Date on which the team retrieved/checked the source |
| state | State associated with the record |
| district | District associated with the record |
| block | Block/administrative subdivision when available |
| mandi | Agricultural market/APMC when available |
| crop_id | Unique crop identifier |
| season | Agricultural season such as Kharif/Rabi when provided |
| year | Reference year |
| date | Specific observation date |
| production | Crop production quantity |
| area | Cultivated/covered area |
| yield | Production per area |
| min_price | Minimum recorded market price |
| max_price | Maximum recorded market price |
| modal_price | Modal/representative market price when the source provides it |
| arrival_quantity | Market arrival quantity when available |
| MSP | Minimum Support Price when provided by the source |
| advisory_text | Agricultural/weather advisory content |
| page_or_section | Page/section supporting an extracted fact |
| extraction_method | Web/PDF/OCR/API/Excel/manual etc. |
| confidence | Internal extraction confidence, not a government statistic |
