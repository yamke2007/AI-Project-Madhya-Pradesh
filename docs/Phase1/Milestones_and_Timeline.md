# Phase 1 Milestones and Timeline

The following timeline is a proposed project plan for completing and demonstrating Phase 1. Dates are planning targets and should be updated if the team receives a different official submission schedule.

| Milestone | Work | Output | Target |
|---|---|---|---|
| M1 | Confirm state, problem and crop scope | Problem statement + crop scope | Day 1 |
| M2 | Collect candidate official sources | Initial source list | Days 1–2 |
| M3 | Classify modalities, languages and coverage | Source analysis + inventory | Days 2–3 |
| M4 | Verify source URLs and accessibility | Verification log | Days 3–4 |
| M5 | Finalize information entities and fields | Database schema + data dictionary | Days 4–5 |
| M6 | Finalize extraction/tool mapping | Agent and tool plan | Days 5–6 |
| M7 | Complete team roles and contribution plan | Team information | Day 6 |
| M8 | Map repository against evaluation criteria | Phase 1 evaluation checklist | Day 7 |
| M9 | Final repository review | Clean GitHub repository + documentation | Day 7 |
| M10 | Viva/demo preparation | Demo queries + viva notes | After Phase 1 review |

## Completion criteria

Phase 1 should be considered ready for submission when:

- the crop scope is explicitly documented;
- crop stages/activities are explicitly documented;
- sources are listed with modalities and limitations;
- source URLs have been manually checked;
- schema and data dictionary are consistent;
- the agent/tool flow is documented;
- team roles are filled in;
- the repository maps clearly to every Phase 1 evaluation item.
